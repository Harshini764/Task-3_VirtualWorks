# Coffee Rating Application

A simple Node.js + SQLite app that displays a list of coffee items and lets users vote. Each vote updates a count stored in the database.

## Run locally

1. Open a terminal in `e:\VirtualWorks\Task-3`
2. Run `npm install`
3. Run `npm start`
4. Open `http://localhost:3000`

## Features

- Backend API with Express
- SQLite database persistence
- Frontend voting UI
- Vote count updates on every click
- Add new coffee items dynamically
- Reset all vote counts to zero
- Display total votes across all items
